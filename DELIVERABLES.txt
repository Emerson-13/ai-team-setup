🚀 QUICK START FOR USERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Install via Composer:
   composer require emerson/ai-team-setup

2. Publish files to project:
   php artisan ai-team:install

3. Configure MySQL in phpunit.xml:
   DB_CONNECTION=mysql
   DB_DATABASE=app_testing

4. Read the documentation:
   cat docs/ai/TEAM.md

🎯 WHAT EACH FILE DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

composer.json
  → Package definition for Composer
  → Auto-discovery of service provider
  → Dependency specification (Laravel 10+/11+)

AITeamSetupServiceProvider.php
  → Registers publish groups (config, docs, scripts)
  → Registers ai-team:install command
  → Called automatically by Laravel

InstallAITeam.php
  → Artisan command that runs: php artisan ai-team:install
  → Publishes files to correct locations
  → Shows helpful next steps
  → Makes scripts executable (Unix)

README.md
  → Main package page (shown on Packagist)
  → Features, installation, documentation links

INSTALLATION.md
  → Detailed setup guide for end-users
  → Step-by-step configuration
  → Troubleshooting section

PACKAGE-SETUP.md
  → For package maintainers (you)
  → How to structure the repo
  → How to test locally
  → How to publish to Packagist

PACKAGE-CONTENTS.md
  → Quick reference guide
  → File purposes
  → Common tasks and troubleshooting
